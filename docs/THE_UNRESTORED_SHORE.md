# まだ、向こうがある

街は、中央が選んだ記憶から復元されている。建物の形、設備の動かし方、仕事の手順は戻せた。でも、その場所で誰を待ったのか、何をして遊んだのか、なぜそこが好きだったのかは、後回しになった。

街の端の霧は「まだ戻していない記録」の境界。記録そのものが消えたという意味ではない。霧の中に家の輪郭が残り、中央は「そこを好きだった理由が、まだ足りない」と語る。人間が自分で残す時間が、次の街を選ぶ手掛かりになる。

## 境界の見た目

- 大きな青い長方形を、両端で曲がる有限の川へ変更。石の水門をくぐると、水面も小舟も霧の中で見えなくなる。
- 地面の周囲に丸い岸を追加。都市の外周は低い柵、植栽、小さな灯り、その先の丘と薄い霧で囲む。
- 都市内の水路4か所の端も、石のアーチへつながる。
- 北と側面の霧の中に、まだ輪郭しかない家。既存の遊べる地形を保ちつつ、歩ける限界に見える柵を置く。

外側は鑑賞する背景で、この更新で新しい家の内部や、霧を越える地区を解放したわけではない。次の拡張を物語の中で受け止められる境界としている。

## 街の仕掛けがつながる流れ

| 触れる場所 | 物語と景色へのつながり |
| --- | --- |
| 忘れものの回廊 | 中央が仕事を優先して街を復元してきたこと、遊びや遠回りが霧に残ったことを知る。 |
| 風車・水門 | 電力と水の余裕ができ、境界の灯りも強くなる。記憶を残すための余裕と、遊ぶための余裕を両方作る。 |
| 小舟 | 灯りを川へ流す。実際の川筋に沿って28秒かけて東の水門へ進み、霧に消える。 |
| 東の「返事を待つ岸」 | 小舟が到着した後、霧の中で二つの灯りを見る。返事か、昔の誰かの痕跡かはまだ断定しない。現地で調べて初めて、新しい記憶が残る。 |
| 川辺のベル・古い音の店・玄関 | 小舟と同じ三つの音を返す。別々の寄り道で聞いた音が、同じ街の痕跡としてつながる。 |
| 噴水 | 冷却のための水から、何度も遊びたくなる時間が生まれる。訪れた住人もその違いに触れる。 |
| 音の停留所 | 誘った住人が到着すると音が重なり、境界の灯りのリズムも変わる。 |
| 時計 | 機械と外周の灯りが少しずつ異なるリズムになる。中央と完全に足並みをそろえるだけの街に、ずれを作る。 |
| 配達所 | 今はどんな時間を運んでいるかを知る。中央に記憶を預けた後は、次の便にその時間も含まれる。 |
| 望遠鏡 | 名前のない星と、霧の中の家を結びつける。北の「まだ名前のない岸」へ向かう手掛かり。 |
| 北の「まだ名前のない岸」 | 中央が戻せていない街の理由を聞く。自分で持ち帰り、書き直し、人を誘える記憶になる。 |
| 都市の心臓 | 預けただけでは景色は変わらない。次の同期で住人へ届くと、北の家の窓が一つ灯り、店先の返事も変わる。 |
| 同期しない庭 | Shellが実際に来て読むと、庭の周りに小さな灯りが集まる。未共有の本文は中央へ送らない。 |

カフェの「何も注文しなくても、ここにいていい」という言葉も、用途がなくても残したい時間という主題につながる。18の店先には6種類、周辺の玄関には5種類の短い返事を用意した。説明パネルを増やさず、音・景色・一言で気づけるようにする。

岸にも住人を誘える。到着した住人は、霧の正体を解決したと断言せず、そこで自分が過ごしたことを覚える。どの寄り道も必須チェックリストにはせず、最初の約束の後は自分の順番で試せる。

## 続きから遊ぶ場合

再読み込み後、「保存した街の続きから」。以前のブロックと編集はそのまま残る。既に小舟を流した街は、時間条件を満たすと東岸の返事を調べられる。既に記憶を中央へ預けた街で初めて窓の復元を見るには、別の記憶を預けて次の同期を迎える。

新しい操作地点は「返事を待つ岸」と「まだ名前のない岸」。全体で39か所、集められる記憶は9種類、住人の寄り道先も9か所。既存のE・Q操作を使う。

主要な台詞はTTSで事前生成。改稿前のセーブに残る台詞も正しい音声で再生できるよう、新旧の音声ファイルを保持する。自由な記憶からの発話、返答、寄り道先の選択には既存のResponses APIを使用。川・小舟・灯り・記憶を得る条件はゲーム側のルール。

`npm test` で川と小舟の範囲、到着後の現地確認、同期後の変化、庭への到着、旧音声との互換を検証する。実画面の `/?review=1` は110経路を確認。`/?visual=1` に水門と北の岸の視点を追加した。
