# 街で拾う、役に立たない時間

Tomoとの約束の章から、その先の都市へ。中央は街を続けるために、仕事に必要な記憶を優先してきた。橋の向こうの「忘れものの回廊」には、待つこと、遠回り、名前のない遊びの空きがある。人間が街で楽しんだ時間を、どこに残すかを試す小さな続編。

## 遊び方

「この身体で、目を覚ます」で開始。以前の記憶の街は「保存した街の続きから」でも追加部分を遊べる。Tomoとの再会を終えると、画面の短い目標が都市の探索へ切り替わる。探索自体は最初から可能。

1. 中央の裏の橋を渡り、忘れものの回廊をEで調べる。右上メニューの「記憶の都市へ」でも橋の先へ移動できる。
2. 風待ちの丘で風をつかまえ、川の水門を開く。風車・鈴・水車が動き、電力と冷却水の流れが増える。
3. 噴水、音の停留所、小舟、望遠鏡などにEで触れる。経験したことが自分の記憶のブロックになる。
4. Qで集めた記憶を先頭に入れ、住人に話す。自由な文章にも書き換えられる。住人が誘いを受ければ、目的地まで歩いてから、その経験を覚える。
5. 残したい記憶を先頭へ入れ、都市の奥の心臓か、同期しない庭でE。

普段の画面に操作ボタンは追加しない。近くで向いている対象一つだけに、Eで行うことを表示する。近くの住人を向いているときは、その住人への会話を優先する。

## 二つの残し方

| 場所 | 起きること |
| --- | --- |
| 都市の心臓 | 風と水を整えた後、先頭の記憶だけを中央へ預ける。次の同期で4人の現在の文脈に届く。中央との既存のRealtime・文字会話からも、この預けた内容を参照できる。 |
| 同期しない庭 | 先頭の記憶だけを庭に残す。Shellが歩いてきて直接読み、庭に誘ったほかの住人も到着時に読める。中央には内容を送らない。花が育つ。 |

両方を試せる。預けた文章は、その時点の写し。後から自分のブロックを書き換えても、預けた内容は勝手に変わらない。もう一度その場所でEを押すと入れ替わる。身体の2・3番目のブロックや保管中の文章は一緒に送らない。庭の文章を読んだ住人が、その後の会話で共有を選んだ場合は、通常の共有ルールに従う。

## 街の追加

- 都市内の水路2本と14本の小橋。水路は歩けず、橋を通る。水面、睡蓮、小舟が動く。
- 18棟の店先に6系統の配色・看板、庇、窓、品物、花箱、呼び鈴。周辺の5軒もノックに応える。
- ベンチと植木鉢、音の停留所、噴水、配達所、庭、ずらせる時計、望遠鏡、中央へ渡す端末。
- 既存のBlender製風車を使った大小の風車、水車、風鈴、小舟の船着き場、川岸の石と葦。
- 記憶の配達機10台が街を巡回する。水路は橋で渡り、人や住人の手前で待つ。

Eの対象は37か所。経験から残る記憶は7種類で、同じ場所を連打しても増殖しない。住人を誘えるのは丘・水門・回廊・噴水・音の停留所・庭・望遠鏡。すべての建物の室内や、背景の全メッシュに操作を付けたわけではない。店先の返事は短い音・明かり・文章で、追加の店員エージェントは置いていない。

## 実装と検証

物を触る反応、物語の主要な台詞、資源条件は設計したゲームルール。自由な記憶からの身体の発言と、その発言を聞いた住人の返答・目的地選択にResponses APIを使う。新しい `visit` 行動の目的地はサーバーで検証する。オフライン時は明示した簡易解釈。主要な探索の台詞はTTSで事前生成し、物の操作をAPI待ちにしない。

見た目は既存のモデルとThree.jsの形状を組み合わせたもの。静的な小物は形状と材質ごとにインスタンス化。地面と道路から水路を切り抜き、同じ水路の定義を通行判定にも使用する。配達機には移動する衝突形状を付ける。

`npm test` は記憶の重複防止、距離・世代・二重操作、資源の変化、中央と庭の伝達範囲、到着前後の記憶、古い進行との互換、HTTP経路を検証する。実APIでも集めた記憶から `visit: music` を選ぶところを確認。`/?review=1` は実際の街の衝突形状を使って、操作地点と住人の目的地を含む100経路を検証する。`/?visual=1` の確認画面に都市の水路・店先・心臓・丘の視点を追加した。

長期の結末、庭から住人同士へ自律的に語り継ぐ連鎖、記憶の内容に応じた自由な建築は今後の範囲。今回は、街で経験し、その記憶で誰かを誘い、残し方による違いを見られるところまで。
