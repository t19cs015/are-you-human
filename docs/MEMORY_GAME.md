# 自分で、覚えている — 記憶の最初の章

同じロボットの身体を持つ住人たち。中央は街を続けるために、次の身体へ渡す記憶を選んでいる。人間が操作する身体だけは、その選択を自分で変えられる。

中心になる遊びは **経験する → 記憶を選ぶ／書き直す → 自分の声を聴く → 相手の選択を見る**。相手の記憶は画面に一覧表示しない。知っているはずの約束に首をかしげる、一緒に歩き始める、別の住人を誘う、という反応から確かめる。

## 今回遊べること

タイトルの「この身体で、目を覚ます」から開始する。従来の街やMiaのエピソードとは別のセッション。

1. 目の前のTomoにEで応え、次の灯りの下で星を見る約束をする。
2. 中央が住人を同期する。住人は止まり、自分だけ動ける。同じTomoにもう一度声をかけると、先ほどの約束を覚えていない。
3. Qで自分の記憶を開く。「ここで、また」を一番左へはめて、Tomoに話す。記憶の意味から自分の言葉が生成される。
4. Tomoが誘いを受け入れると、実際に広場へ歩く。到着して初めて新しい経験が残り、TomoからShellにも誘いが伝わる。
5. 新しい経験を先頭にして、次の自分にも残すことを相談できる。住人が共有を選ぶと、その時点の経験を中央が預かり、次の同期でその住人へ返す。共有していない住人の文脈は入れ替わる。

誘いを受けるか、話を聞くか、仕事に戻るかは生成された住人の判断。同じ文章が必ず同じ答えになるとは限らない。別の記憶の順序や、自分で書いた言葉を試せる。

## ブロックの操作

- つまんで三つのスロットへ。入っているブロック同士は交換できる。左ほど発言に強く影響する。
- 下の保管場所へ戻すと、身体から外れる。記憶そのものは残る。
- ダブルクリック、タッチの長押し、キーボードのF2で裏返す。自然言語で240文字まで書ける。白紙のブロックは一度触れるだけで書き始められる。
- Enterで残して表へ戻る。Shift+Enterは改行。日本語入力の変換確定中は保存しない。外側を触れても保存する。
- キーボードやクリックだけでも、ブロックを選んで置き場所を選べる。Qまたは×で街へ戻る。

書き換えるのは、身体が現在参照する主観。実際に起きた出来事、他人の記憶、街の権限は変わらない。自分が目撃したことは盤面下部に別に残る。

## 中央と物語の方向

中央の役割は「次に何を覚えて生きるか」を選ぶこと。灯りや水、街の継続を支える記憶を優先すると、一人との小さな約束が抜け落ちる。住人にとっては、その配分が当たり前だった。

最初の章の目標は、住人自身が残したいと決めた時間を、次の同期へ持ち越すこと。続く章では、中央と保存の方針を変える道、中央へ預けずに住人同士で伝える道、その結果として街の仕事や関係が変わる展開を検討する。資源の配分を伴う選択、反中央ルート、複数の結末はまだ実装していない。

「人間だから永久に覚えている」だけでなく、「何を自分として残すかを自分で選べる」という違いから始める。AIの住人も残したい経験を選び始めると、Are You Human? の問いが住人にも返ってくる。

## AIとゲームの分担

通常の会話は二つのResponses API呼び出しで作る。最初は身体に入れた記憶だけからプレイヤーの発言を生成。次は、その発言と住人自身の現在の文脈だけから、返答と行動を生成する。住人にはプレイヤーの未発話の文章や保管中のブロックを渡さない。中央にも未共有ブロックを渡さない。共有後に交わした別の内緒話は、先ほどの同意に含めない。

行動は `meet / share / work / listen` の範囲で検証して適用する。近距離、編集中の世代、二重リクエストもサーバーで確認。同期で現在の文脈と短期会話を差し替えても、出来事のアーカイブと人間のブロックは残る。保存・再開に対応。

導入の約束、最初の忘却、到着後の台詞とShellへの誘いは演出として設計済み。未接続・上限・モデル応答の不備では、明示したデモの解釈に切り替える。オフラインの自由文解釈は簡易ルールで、実APIと同じ能力ではない。

既定の接続は `.env` の設定を使用。導入の11音声はTTSで生成済み。自由な発言は実行時にTTSを生成し、キャッシュする。声を止める操作と音声OFFを用意。中央の既存のRealtime会話にも記憶の章の状況を渡す。マイク入力の動作は今回の記憶の変更とは別の既存機能。

## 身体と制作物

陽菜の住人たちに合わせたアイボリーとセージ色の身体。胸に開くハッチと三つのカートリッジ、袖と手を追加した。歩行中は一人称の手元、俯瞰では身体全体を表示する。

- 編集用: `art/characters/player.blend`
- ゲーム用: `assets/characters/player.glb`
- 再生成: Blenderで `scripts/build-player.py` を実行
- 全身の確認: `/character-review.html` の「あなた」
- 音声の再生成: `node scripts/build-memory-voices.mjs`（設定済みのTTS APIを使用）

`npm test` で同期・主観と事実の分離・自由文の文脈境界・到着判定・共有同意・保存復元・HTTP境界とモデル構造を確認。`/?review=1` は実際の街の衝突形状に対する通行確認を表示する。
