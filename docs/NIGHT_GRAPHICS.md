# 夜の街のグラフィック調整

陽菜の住人と街の色を引き継ぎ、温かいミニチュアの夜として光と素材を仕上げた。

## 画面で変わったこと

- 空を深い青から淡い紫へ変わる夜空にし、月と小さな星を配置。
- 柔らかい環境光の映り込み、暖色の照明、控えめなブルームを追加。影の範囲は歩く位置に追従し、中央の奥でも建物の陰影が出る。
- 住人の足元と静的な障害物の下に薄い接地影を追加。
- 石畳の角を丸め、粒子状の凹凸と色の差を追加。土と舗装にも細かな材質を持たせた。
- 川面の頂点と法線を小さく動かし、月明かりの反射が揺れるように変更。川の遠い端は夜へ溶け込む。
- 6系統のビルに窓枠と桟を付け、暖色・寒色・消灯した窓を混在させた。
- 記憶の都市の顔と輪が一緒にこちらを向く。顔の前を横切る支柱を取り除き、足元の投影器から浮かぶ表現にした。
- 分配器の丸み、留め具、額付きの札を仕上げた。札への本体の食い込みを解消。近くで大きく見えていた粒子は、小さな柔らかい光にした。
- 木製道標は板の厚さを確保し、どちら側からも文字が支柱に隠れないようにした。

## 描画の設定

メニュー → 操作と設定 → 音声・操作の設定 → 画質。

「自動」を既定にし、描画に時間がかかると解像度を段階的に下げる。「きれい」は解像度を優先。「軽く」は解像度を下げ、ブルームを省く。選択はブラウザに保存する。

16個の点光源を使い回し、近い照明を優先して描く。ビルの窓は単純なインスタンスで描き、成長量が同じなら行列を再送しない。画面の外にあるビルも描画対象から外せるようにした。

## 確認方法

`/?visual=1` で開始すると、広場・カフェ・住宅の入口・中央への道・中央・記憶の都市・川辺へ移動できる。「光の仕上げ」で照明と後処理を切り替えられる。形状や水面の変更は両方に適用される。

パネルには直近180フレームの平均時間、95パーセンタイル、描画回数、三角形数、解像度倍率を表示する。視点を変えてから数秒待って読む。通常のURLにはこのパネルを表示しない。

検証：既存の74テストが成功。GLB読み込み後の通行確認は31/31経路。ブラウザが必要とする56モジュールのHTTP配信とJavaScriptの構文を確認した。実Chromeで画質3種類、再読み込みによる設定保持、分配器の灯りの切り替え、各地区の描画を確認。WebGLシェーダーのエラーは検出していない。

測定した2880×1542の画面では、「きれい」の広場は約44ms/フレーム、「軽く」の住宅前と川辺は約16.7ms/フレームだった。視点・解像度・端末によって負荷が違うため、通常は自動設定で遊ぶ。
